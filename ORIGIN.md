# Origin and authorship boundary

This repository is a public portfolio artifact authored by Dmitry Nesmachny.

The professional experience represented by this case is based on a technical solution for integrating an enterprise platform with centralized identity and access management. The original technical solution was authored by Dmitry Nesmachny.

The original corporate document is **not published, copied, or mechanically anonymized** here. This repository is a clean-room synthetic reconstruction created specifically for public portfolio use.

The public case intentionally replaces or removes:

- organization, project and system names;
- document identifiers and internal terminology;
- domains, service accounts and network parameters;
- real role/group identifiers;
- employee names and approval chains;
- internal security and operational procedures;
- original diagrams and text fragments.

The repository demonstrates the architecture reasoning behind the work: separation of provisioning from runtime access, directory-group-based authorization, approval-governed access lifecycle, environment separation, segregation of duties, reconciliation, and failure containment.
